# Morfi · kit de referencia para Codex

Este paquete contiene **15 PNG originales**, el prompt completo en Markdown, un índice y un manifiesto con dimensiones y huellas SHA-256. Las imágenes se copiaron sin modificar sus píxeles ni recomprimirlas.

## Cómo usarlo con un repositorio vacío

1. Descomprime este ZIP.
2. Copia **el contenido** de esta carpeta a la raíz de tu repositorio: el archivo `PROMPT_CODEX_MORFI_3D.md` y la carpeta `references/` deben quedar accesibles allí. Conserva también el índice y el manifiesto.
3. Abre el repositorio con Codex. Si es una tarea remota que no puede leer archivos de tu computadora, sube primero estos archivos al repo o adjunta el ZIP a la tarea si el entorno permite descomprimir adjuntos.
4. Dale la instrucción corta que aparece abajo. El prompt completo ya contiene las especificaciones para empezar desde cero.

```text
Lee íntegramente PROMPT_CODEX_MORFI_3D.md y abre visualmente las 15 imágenes de references/. Ejecuta ese encargo completo en este repositorio: modelo 3D real de Morfi, fuente editable, materiales suaves, GLB, renders y visor de inspección. La referencia principal es references/00_Morfi_master_wordmark.png. Resuelve las diferencias entre imágenes siguiendo la prioridad del prompt y valida con renders reales. No te detengas en un plan ni en un prototipo de primitivas. Conserva las referencias originales y documenta con honestidad cualquier limitación pendiente.
```

## Qué incluye

- 1 imagen de Morfi definitivo con wordmark.
- 1 lámina de seis ángulos y laptop.
- 6 vistas individuales del personaje vestido.
- 7 imágenes de elementos: sudadera, playera, tenis, lentes, tres cubos, laptop y cuerpo base.

Las referencias son renders ilustrativos independientes: pueden variar ligeramente en proporciones, textura, accesorios y perspectiva. El encargo establece una referencia maestra para obtener un único modelo coherente. Un prompt detallado no garantiza una réplica exacta de manera automática: el resultado depende del modelado, las herramientas y la revisión visual.

Este ZIP es un **kit de instrucciones y referencias**, no contiene todavía un modelo 3D ni un proyecto implementado. Todos los fondos de los 15 PNG originales incluidos son claros/opacos; el prompt solicita transparencia real para los renders nuevos que produzca Codex.
